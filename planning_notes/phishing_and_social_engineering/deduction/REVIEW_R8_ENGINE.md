## Verdict

**Ready to build: no**, because of one major. R8E-1 came in with the R7E-10 fix. Under a credits ending,
the gate global DL22 allows `onClose` to set is no longer set before the step-3 post-check, so Finish loops
and the credits never roll. The fix is one clause in §5.5 step 3 plus one §11.3 case, with no server
change. With that folded, the plan is ready; the four minors can be folded at the same time or left to
the owning packets (P10-U1 for R8E-2, R8E-3 and R8E-5, P10-W/S18 for R8E-4).
