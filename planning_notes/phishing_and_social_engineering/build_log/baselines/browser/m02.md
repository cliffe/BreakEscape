## How the values were read

An in-page hook was installed with `eval` after bootstrap (and again after the reload, so the post-reload hook started later than page boot): a MutationObserver recording every `.influence-popup` node, `console.error`/`console.warn` wrappers, `error` and `unhandledrejection` listeners, and a `console.log` filter for the `Influence increased/decreased` lines. No `window.__test` method gives these, so this is page code and not a bridge feature.

- Ink `influence` per NPC: `window.npcConversationStateManager.conversationStates.get(<npcId>).variables`. This map is written when a conversation closes, so there is no mid-conversation reading. Only before and after exist.
- Game globals: `window.gameState.globalVariables`.
- Hostile: `window.npcHostileSystem.isNPCHostile(<id>)`. Chosen because it does not create a state (`getState` does, per the skill).
- Observer caveat, mine: before the reload my observer counted a popup twice whenever its container `div` was freshly created (the container node and the popup node both matched). The pre-reload popup list therefore shows pairs at identical timestamps. The accurate pre-reload count is the number of `✨/⚠️ Influence ...` log lines. I fixed the observer for the post-reload half (WeakSet de-dupe), so the post-reload counts are direct. The table below uses de-duplicated numbers.
