## Script

`tools/playtest/se/bridge-4.jsonl`: 66 lines, 30 `eval` assertions. Every assertion returns a boolean. The first words of each `fn` are the row label. Sections: S0 baseline; Q Quinn (`quinn_desk` / `quinn_floor_call`); P Brandt prep (`slice_desk_phone` / `brandt_desk_call`); C the call; reload; R restore; L lockout. Each phone interact is preceded by `moveToNear`.

Object-valued globals are read from `window.gameState.globalVariables`. `__test.getState().globals` stringifies objects (`state.js` `globalsState`), so a session log read through it is the string `"[object Object]"` and `st.open` is missing. Primitive globals in P4 and P5 still use `getState().globals`.

The lockout toast lasts 2500ms. `interact()` then waits about 4s for an effect that never comes (`confirmEffect` timeout 4000ms), so the toast is gone if the assertion looks afterwards. L5 records `.notification-message` text during the interact.

R4 waits up to 10s for the tell text. The phone bar is mounted when the conversation header opens. The tells are drawn later, inside `attachPretext`, after the ink load.

The scratch generator (`se-P4-T0/build.mjs`) is behind this file. Regenerating from it would drop `moveToNear`, the R1 global source, the R2 null check, the R4 wait and the L5 toast poll.
