## Limits of the script

- Tab order is checked as in bridge-1a: every visible control is tabbable, none has a positive tabindex, DOM order matches the expected labels, and each takes focus when `.focus()` is called. Synthetic key events do not move browser focus, so a real Tab-key walk is not simulated.
- Space and E are the keys the Phase 2 "Done when" line names. WASD and the arrows are included as well, matching the board row in `bridge-1a.jsonl` (B2). On open, focus is the browser root, so the strip's arrow-key handler does not move the page. The check is that the player and the location stay put.
- The tools panel is not opened. The §2.2 row does not name it. The Esc sub-panel in the "Done when" line is the document properties panel, which O4 and O5 cover.
- Hampshire's other Careers fact (`careers_attachment`) and the Teague facts are not collected. The row asks that granted facts survive a reload, and these two do.
- Reload uses `?skip_resume=1`, as in bridge-1a. A plain reload shows the Resume overlay, which `bootstrap` refuses to click.
- A first draft, on game 2927, looked for the Careers link while the restored page was the document, so that link was not in the page. The final script opens the company site first (line 26). That was a script mistake. The browser did restore the saved page.
