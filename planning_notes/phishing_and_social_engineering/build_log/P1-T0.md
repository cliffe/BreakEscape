## Limits of the script

- Tab order is checked as: every visible control is tabbable (`tabIndex >= 0`), none has a positive tabindex,
  DOM order is the expected order, and each takes focus when `.focus()` is called. Synthetic key events cannot
  move browser focus, so a real Tab-key walk is not simulated.
- Not covered (not in this phase's slice): the blank picker and account switcher (1b, `bridge-1b.jsonl`), the
  600 px layout (1b/P1-N).
- Reload navigates to the game URL with `?skip_resume=1` rather than `location.reload()`, because the page
  strips that parameter on load and a plain reload shows the Resume overlay (which `bootstrap` refuses to click).
- Facts are granted by interacting with the three notes in the slice, so the facts are earned in-game. Nothing
  was typed from a solution guide or set from the console.
- Mail close results are read from the bridge's event log (`peekLog`) after a `note` marker.
