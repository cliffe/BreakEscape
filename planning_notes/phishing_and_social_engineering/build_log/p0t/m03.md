## The DIFFERENT lines

1. **Ffion popups: 10, not 11.** Static count: `m03_npc_ffion_rees.ink` emits exactly 10 `# influence_increased` tags on the
   baseline's choice path (confirmed by running the compiled story in Node with those choices: 10 tags,
   `receptionist_influence` 55; the 11th choice, "Lean in", carries no tag). In game, 10 tags gave 10 popups and 10
   influence log lines, in both 2843 and 2846. The baseline's first two popups share a timestamp (t=22408), so its extra
   popup looks like a duplicate on the first tag. `showInfluencePopup` (`chat-helpers.js:746`) and its
   `influence_increased` case (`:204`) are byte-identical to HEAD~. I cannot tell from here whether the duplicate
   disappeared because of a Phase 0 change or was timing-dependent in the baseline. Either way popups now equal tags.
   If a duplicate was intended to be a reference count, the plan's "11" should become 10.
2. **Victoria popups: 5, not 9.** `victoria_influence` still reaches 45. The path has +10 and +15 tag lines, so five tags
   (45 in total) fit and the baseline's nine would need all-+5 steps, which this route does not take. As with Ffion, popups
   now match real tags and the baseline's 9 is probably four duplicates. Not simulated end to end (the cloner return needs
   the engine), so this is inference, not proof.
3. **Ffion post-reload hub lacks "Lean in".** Expected: I cloned the badge before the reload. Not a regression.
4. **New `superseded minigame instance` warn** at the Victoria Darkside Save (`base-minigame.js:90`). The guard is old (commit 75a117aa),
   the same message is in the m02 and m05 baselines, and it returns harmlessly: the save, the task, the global and the return to
   the chat all worked. It sits on the new returnTo/suspend path (`minigame-manager.js`, `_startReturnTo` and the `suspended`
   handling in `endMinigame`), so a deferred person-chat complete after the parent was swapped out is a plausible source.
   Not seen in the Ffion cloner flow.
5. **Console minor:** `[TTS] Play failed: Audio load timeout` (keyless server) and conference-room pathfinding warn 2x
   against 3x.

No blockers, no loss of state, no behavioural regression found. Not edited.
