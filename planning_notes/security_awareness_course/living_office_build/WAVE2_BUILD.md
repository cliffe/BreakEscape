## 2. Work packages

Every package works in its own worktree made by hand from `feat/ca-living-office-w2` (memory: agent worktrees drift to the wrong repo), on a branch `w2/<package>`, and commits only the files it owns. The integrator merges. No two packages write the same file. Where a file passes from one package to another, the table says so and the hand-over is a merge.

### Standing rules for every package

- Never commit on main. Stage explicit paths; check `git diff --cached --stat` before each commit. Commit before testing; fixes are follow-up commits.
- Generators and `apply_training_room.py` run only with `--repo <own worktree>` and a scratch out dir (confirm the exact flag names with `--help`; `gen_e1_shells.py:475` shows the old default). Copy back only the files the run is meant to change. Move any `dungeon_graph.*` churn to `tmp/delete/`; never `rm`.
- Proof 5 (byte-identity of a full regeneration against HEAD) passes before any generator change and again after it, on every shell the change is not meant to touch.
- The pin test keeps the 28 check shells, the annual shell and the `room_aw_*` maps byte-identical. Changing a pin needs the owner's yes.
- No `db:` task and no game-record edit. Live proofs use keyless servers on :3001 to :3005 from a worktree (`bundle exec`, `BUNDLE_PATH` pointing at the main checkout's `vendor/bundle`). Never touch :3000. Stop servers by PID only.
- Headless runs call `window.__test.throttleFps(20)`; fixed steps stay on.
- Every NPC pool under a gated key carries its own `requireGlobal: { "kit_quiet": false }`. Stub knots end on the sticky `+ [See you later.]` with `#exit_conversation`. Speaker prefixes are full display names. A kit pool is spoken only through an engine-spoken topic: one source per company carries `affordance.chatter: "pool"` with `capacity: 2` (T:221-222). Carrholme has no source (PLAN 4.2): P-KC confirms what T requires of a sourceless company and records the decision.
- Every kit shell carries both quiet releases (`done.includes('debrief')` and `debriefSeen === true`), `npcThoughts: false` at top level, `kit_ep` declared with its own episode id, and the kiosk finished variant keyed on `kit_defend_done === true && kit_quiet === false` only where `stepAway` is true (none in wave 2).
- Removing a mapping leaves an inert "Retired <date>" slot (condition `data.retired_<date> === true`). New `eventMappings` go last. Run `ruby tools/check_mapping_index_drift.rb main` before sending a hash.
- Node asserts are booleans (`assert.ok(a === b)`). A new static import in an engine module is added to every test harness copy list.
- `bin/rubocop` on any touched Ruby file (`BUNDLE_PATH` set in worktrees).
- npc-dialog-review (section 2l, P1 to P13) runs on every batch of new lines before any voicing question. Voicing needs its own owner yes, sent through AC0.
- Content rules (CA01_DIALOGUE_EDITS.md, CA12_BUILD part 3): short natural speech, not policy; nobody blamed; no line says who let the incident in; no figure from layer 1 repeated by the host; less secure answers carry a real reason; no reusable method, tool, command or wording in layer 0 (ca13 and ca14 stay consequence-only); money as description, not a number. UK English, "Cyber Security".
- Owner aim: fun and immersion, and the attacker's side told in attacker terms.
- Each agent writes its handover at about 150k tokens or 80 calls, commits, and stops.

| id | file:line | speaker (full display name) | voice | line (exact text) | kind | voiced or written | branch |
