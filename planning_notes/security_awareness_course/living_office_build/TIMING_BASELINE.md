# Living office wave 0: timing baseline

Measured 2026-11-19 on `feat/ca-living-office-build`. Part 1 is a static count. Part 2 is a replay of the seven full-episode bridges on the keyless server. Generated by `scratchpad/timing/part1.py` and `bridges/summary.tsv` (scratch files, not committed).

## Assumptions

- Assumption: the learner text is every non-config string under the `social` key, with all-lowercase machine tokens (ids, `pass`, `lookalike_domain`) dropped. ERB tags were stripped, not rendered, so any text ERB generates is not counted.
- Assumption: ink words are prose only, after removing VAR, CONST, LIST, INCLUDE and EXTERNAL lines, comments, diverts, tags and choice markers.
- Assumption: the word count sums every ink branch and every triage item, so it is an upper bound and no single learner reads all of it. Reading time is words / 200.
- Assumption: `ca17_acceptable_use_defend` has no full partner, so it is a twin and uses the 8.5 limit.
- Assumption: the keyless server on :3001 was started for this run and stopped afterwards. Each bridge got a fresh game from `bin/rails runner tools/playtest/new-game.rb`, which creates rows in the shared dev DB and edits none.
