## Cyber Security accuracy

- **USB drops.** Tischer et al., "Users Really Do Plug in USB Drives They Find" (IEEE S&P 2016; recalled, not fetched): most dropped drives were picked up and close to half were plugged in with files opened, and most people who answered the follow-up said they did it to find the owner. That supports Joanne's "see whose it is", Nilesh's "Kindness does the attacker's work" and the session note's "opened a file to find the owner". "Corners don't get found" is a game simplification of "bait goes where people pass and pause"; the paper does not test corners, and the line claims nothing a practitioner would object to.
- **"A real stick would have run its payload."** Off screen in this script. For the record: AutoRun from USB storage has been off by default in Windows for years, so a real payload runs when the finder opens a file on it or when the device poses as a keyboard. "She opened a file" fits that. No change.
- **"Found sticks go to IT, unplugged."** Matches NCSC removable-media advice (10 Steps, recalled) and the scenario's own `kindLine`.
- **Personal inbox broken into with a reused password.** Credential reuse is a common cause of personal mail account takeover; awareness-level and accurate.
