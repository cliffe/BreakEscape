## New findings

### R3-1 (major): a step written without an article now passes the text rules

- **Where:** `scripts/realism_text_rules.rb:41` (`STEP_NEXT`), `:124-125`; `docs/ACCESS_AND_NETWORKS.md:1340`.
- **What is wrong:** round 2's rule refused a line that starts with an instruction verb followed by any word. To
  let honest lines through, the fix now needs an article, a pronoun, `to`, `in` or a number word after the verb.
  A short `output` line (80 characters at most) is exactly where an author drops the article.
- **How to see it:** `RealismTextRules.check(text, kind: :prose)` returns no error for each of these, and the rules
  at `959795203` refused every one: `Send oversized name field`, `Send 300 characters in the name`,
  `Run check twice`, `Request admin page with blank session`, `Enter 300 letters as name`, `Upload large file`,
  `Set name longer than 64`, `Type admin as user`, `Supply empty token`, `Bypass login with blank name`,
  `Overflow name field`, `Inject long name`, `Trigger fault with long name`, `Then send long name`,
  `State: send long name`, `Delete session cookie`, `Put long name in field`, `Post long name to form`,
  `Craft long name`, `Execute check as guest`. The seven verbs added for R2-6 behave the same way
  (`Use blank password`, `Submit long name twice`, `Visit admin page`, `Open admin page with no session`,
  `Append dots to name`).
- **Why it matters:** the rules are the only mechanical guard on catalog text and must fail closed. This is a move
  from "refuses honest text" to "passes a step", made in this round.
- **Smallest fix:** turn the test round: a listed verb at the start of the line (after an optional label or lead
  word) followed by any word is an error, unless the next word is one of a short list of state nouns:
  `level`, `queue`, `limit`, `protection`, `permission`, `warnings`, `pending`, `mode`, `count`, `size`, `key`.
  A digit after the verb is refused (`Type 2 device` and `Set 3 of 5 loaded` move to N16's list of honest lines
  to reword). Add the lines above to the "refused" test, keep the R2-5 lines that still pass in the "pass" test,
  and bring N16's sentence on refused honest lines up to date.
